First signed, non-debug OpenRow alpha for one invited tester on another Android 9+ Ergatta tablet with a WaterRower S4 USB monitor.

Download **OpenRow-0.22.0-alpha.1-install-kit.zip** on a computer for the USB-stick route, or download **OpenRow-0.22.0-alpha.1.apk** directly in an existing tablet browser. Extract the kit before installation; install the APK. Checksums and the PV&V report are attached. [Start here](https://github.com/cbaum228/OpenRow/blob/main/docs/ALPHA-INSTALL.md).

Includes Gravity Well, Castlebreaker, separate family profiles, local workouts/charts and endurance/general-cardio training. Incorporates the verified XP connection handoff fix and compact object silhouettes. The release disables debugging and removes the visual-lab entry point. The stable signing identity supports in-place updates.

Software verification passed locally: 55,894 JVM assertions, eight completed campaign simulations, 24 native recorder/profile/migration checks and a native XP/reconnect regression against the actual non-debug APK. The workflow repeats source/build/artifact checks before publishing this prerelease.

This is a controlled alpha: second-device installation, physical S4 metric agreement, update retention and a longer session remain tester checks. Personal power-driven gameplay remains disabled; pace fallback is used. Data stays local, with no network permission or cloud backup. Do not uninstall or clear storage to update. Ergatta does not support third-party apps; the install guide describes returning to Ergatta without deleting its software or settings.
